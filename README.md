Live telemetry dashboard built entirely on Android with Termux.

**Creator:** Eric Gichobi @ericgichobi24-star | ERICO TECH

### 🔥 Features
- ECO / NORMAL / SPORT modes
- Battery %, Speed, Power, Motor Temp - updates every 1 sec
- Terminal version (`dashboard.py`) + Web version (`app.py`)

### 🚀 Run
bash
pip install -r requirements.txt
python app.py
Open Chrome -> 127.0.0.1:5000
